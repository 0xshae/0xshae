# 0xshae | Agentic Commerce Engineer 🏴‍☠️

i build infrastructure for the next version of the internet. one where users, agents, wallets, apis, and businesses can safely transact with each other.

right now, i’m obsessed with making the web agent-compatible: payments, api access, rate limits, trust, identity, checkout, and the messy handoff between autonomous agents and real-world businesses.

my work sits somewhere between protocol engineering, ai-native commerce, decentralized identity, and scrappy zero-to-one product building.

## currently building around

* **agentic checkout** — letting ai-assisted buyers discover, compare, and complete actions without breaking existing internet flows.
* **human-aware api access** — verifying when an agent request is backed by a real human, and pricing/routing it accordingly.
* **usage-based software rails** — replacing static subscriptions with budget-constrained execution for autonomous actors.
* **agent identity + reputation** — giving agents verifiable trust signals for commerce, access, and coordination.
* **wallet-native payments** — making crypto payments feel invisible, gasless, and usable for normal people.
